# 📚 MERN BookStore Backend

A production-ready backend for a modern MERN Stack BookStore application.

---

## 🚀 Tech Stack

- Node.js
- Express.js 5
- MongoDB Atlas
- Mongoose
- JWT Authentication
- bcryptjs
- Cloudinary
- Multer

---

---

## ✨ Features

- JWT Authentication
- Role Based Authorization
- Book Management
- Category Management
- Cart
- Wishlist
- Orders
- Reviews & Ratings
- Cloudinary Image Upload
- Global Error Handling
- RESTful APIs

---

## 🛠 Installation

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

---

## 🔒 Environment Variables

Create a `.env` file using `.env.example`.
