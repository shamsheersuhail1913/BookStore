# Book Store

A full-stack Book Store application with a React frontend and an Express/MongoDB backend.

## Project Structure

- client: Vite + React frontend
- server: Express + Node.js backend

## Development

### Frontend

```bash
cd client
npm install
npm run dev
```

### Backend

```bash
cd server
npm install
npm run dev
```

## Deployment

This project is ready to be pushed to GitHub and deployed using GitHub Pages for the frontend or a hosting platform for the backend.
